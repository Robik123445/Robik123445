## Project Alfa 2030

I'm building **Project Alfa**, a long-term autonomous robotic woodworking workshop project targeted for **2030**.

The goal is to connect the complete production workflow:

`CAD → CAM → machine control → vision → automation → production`

into one modular and practical system.
